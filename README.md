# FoodBridge – Food Donation and Distribution System

## Project Overview
FoodBridge is a Spring Boot application designed to support food donation and distribution by connecting food donors with organizations that request food.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Spring Security
- Postman

## Main Features
- User registration with role-based access
- Food donation management
- Food listing and food request APIs
- Admin-related functionality
- Input validation and exception handling
- REST API testing using Postman

## Database
MySQL database: `food_waste_db`

## Running the Project
1. Configure your MySQL database.
2. Set your database credentials using environment variables.
3. Run the Spring Boot application.
4. The application starts on port `8080` by default.

## Note
This project was developed for learning and demonstrating Spring Boot REST API development.
